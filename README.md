# AceLens

AceLens for Windows: your junior tennis tournaments, the whole field in one list, draws, entry deadlines, a points plan and a UTR forecast.

- **Website:** https://inbantamizhselvan.github.io/acelens/
- **Download:** [latest installer](https://github.com/inbantamizhselvan/acelens/releases/latest/download/AceLens-Setup.exe) (Windows 10/11, 64-bit)

AceLens needs an activation code to run (one licence per PC). See the website for how to buy.
